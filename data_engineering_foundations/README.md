## What skills do data engineers need?

* Linux and command line
* Prior programming experience in Python, Java, or Scala
* SQL
* Distributed systems
* Data ingestion
* Processing frameworks
* Storage engines
* Tools associated with each skill

## Data Engineer vs Data Scientist

* Data engineers build and maintain scalable data architectures, streamline data acquisition from multiple sources, clean corrupt data, and ensure smooth data pipelines. They often work with cloud technologies like AWS, Azure, or Google Cloud.
* Data scientists analyze the clean data provided by data engineers to mine patterns, build predictive models using machine learning, and derive insights that influence business decisions.

## Essential tools for Data Engineering

* Data engineering tools fall into three main categories: databases for storage, processing frameworks for handling large-scale data operations, and scheduling tools to automate and order data workflows.
* Common databases include MySQL, PostgreSQL, and MongoDB; processing tools include Spark, Hive, and Kafka; scheduling tools include Apache Airflow, Oozie, and Luigi.
* A data engineering pipeline typically extracts data from multiple sources, transforms it using processing frameworks, and loads it into analytical databases, all managed and scheduled to run efficiently.

## Databases and their types

* Databases are organized collections of data designed for efficient search and retrieval, managed by database management systems (DBMS).
* Data can be structured (like tables in relational databases), semi-structured (like JSON with key-value pairs), or unstructured (like photos or videos).
* SQL databases (e.g., MySQL, PostgreSQL) are relational and use schemas to define table relationships, while NoSQL databases (e.g., MongoDB, Redis) are often schema-less and handle semi-structured or unstructured data.
