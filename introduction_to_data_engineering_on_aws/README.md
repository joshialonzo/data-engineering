## Terminology

* Data Engineering: It is the practice of designing and building pipelines that transform and transport data from various sources into a unified, usable format. These pipelines collect data into a single warehouse, creating a reliable source of truth for data scientists and business analysts.
* Data Engineers Mission: Mata engineers make data accessible and ready for analysis and decision-making.

## The Data Science Hierarchy of Needs

From the bottom (1) to the top ().

1. **Data Collection**: The process of gathering data from various sources, such as databases, APIs, and streaming platforms.
2. **Data Storage/Moving**: The process of storing collected data in a structured and organized manner, such as in data warehouses or data lakes.
3. **Data Exploration/Transformation**: Cleaning, anomaly detection, prep.
4. **Data Aggregation/Labeling**: Analytics, metrics, segments, aggregates, features, training data.
5. ****Learn/Optimize**: A/B testing, experimentation, simple M/L algorithms.
6. **AI/ML**

## Venn Diagram

* Data Engineering is in the intersection between Software Engineering, Business, and Analytics.
* These are specialities: Data Infrastructure, Data Mining, Data Warehousing, Data Crunching, Data Modeling, and Metadata Engineering.
